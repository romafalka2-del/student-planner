# Student Planner
Удобный инструмент для планирования учебного процесса, отслеживания дедлайнов и организации задач.

### Возможности планировщика:
* Ведение списка учебных задач
* Отслеживание статуса выполнения
* Управление приоритетами и дедлайнами

Текущая версия проекта: **1.0**

### Целевая аудитория и принципы использования
Данный планировщик разработан специально для студентов высших и средних учебных заведений. Главный принцип работы — простота, наглядность ведения списков и фокус на актуальных академических дедлайнах.
